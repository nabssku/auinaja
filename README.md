# AUinAja — AU Fake Chat & Social Media Simulator 💬

**AUinAja** adalah web app generator simulasi chat WhatsApp & postingan media sosial untuk kreator Alternate Universe (AU) di TikTok, X (Twitter), dan Instagram.

---

## ✨ Fitur Utama
- **WhatsApp Chat Generator**: Simulasi chat realistis (iOS Notch/Dynamic Island & Android).
- **Pixel-Perfect Styling**: Mendukung WhatsApp Dark Mode & Light Mode.
- **Message Types**: Bubble pengirim (hijau), penerima (putih), date divider, voice note (durasi + waveform), dan media image attachment.
- **Bulk Script Converter**: Paste dialog naskah format `[A]:` dan `[B]:` langsung jadi susunan bubble chat instan.
- **High-Res Export**: Render ke gambar PNG 3x pixel ratio jernih siap upload TikTok Carousel.

---

## 🚀 Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS v4 + Lucide Icons
- **Canvas / Export Engine:** `html-to-image`

---

## 🛠️ Cara Menjalankan Lokal

```bash
# Clone repository
git clone https://github.com/nabssku/auinaja.git
cd auinaja

# Install dependencies
npm install

# Jalankan dev server
npm run start
```
Akses di browser pada `http://localhost:3000`.
